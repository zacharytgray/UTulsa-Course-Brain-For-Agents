# CS-2123 — 2026-08-26

Deleting from a singly linked list: you need the node before the one you are
removing, so either walk with two references or look one ahead. Then doubly
linked lists, where each node also points backward, which makes deletion local
but doubles the pointers you have to keep correct. Mentioned a sentinel head as
the usual way to kill the empty-list special case.

## Transcript

Dr. Example: Wednesday. Deletion. Everybody has their insert working?
Student: Mostly.
Dr. Example: Mostly is Monday's problem. Here is today's.
Dr. Example: To delete a node you have to change the pointer that aims at it.
That pointer lives in the node before it. And a singly linked node has no way to
look backward.
Dr. Example: So you walk with two references. Call them prev and cur. Move them
together. When cur is the node you want, set prev.next to cur.next.
Student: What if the node you want is the head?
Dr. Example: Then prev is null and you set head to head.next instead. That is the
special case everyone forgets, and it is why your tests should always delete the
first element.
Dr. Example: There is a trick to make the special case disappear. Put a fake node
at the front that holds no real value. A sentinel. Now every real node has a
predecessor and the code has one path.
Dr. Example: Second half. Doubly linked lists.
Dr. Example: Each node gets a prev pointer as well as next. Now a node knows its
own neighbor on both sides.
Student: So you can delete without walking?
Dr. Example: If you already hold the node, yes. node.prev.next = node.next, and
node.next.prev = node.prev. Constant time, no search.
Dr. Example: The price is that every operation now maintains two pointers instead
of one, and if you update one and forget the other the list is quietly corrupt.
Dr. Example: A corrupt list does not crash. It just walks off in a direction you
did not intend, which is worse.
Dr. Example: Draw it. Every time. Boxes and arrows, then code.
Dr. Example: Friday is stacks and queues, which are both just this with the ends
locked down. Homework one is due a week from Monday.
