# CS-2123 — 2026-08-24

First look at linked lists. A node holds a value and a reference to the next
node; the list itself is just a reference to the head. Compared against arrays:
insertion at the front is constant time, but there is no random access, so
finding the k-th element costs k steps. Ended on the insert-at-front code and
promised deletion on Wednesday.

## Transcript

Dr. Example: All right, everyone. Today we start linked lists.
Dr. Example: Last week you had arrays. An array is one block of memory and every
element sits next to the last one. That is why arr[7] is instant.
Dr. Example: A linked list gives that up. Each element is its own little object
somewhere in memory, and it holds a pointer to the next one.
Dr. Example: We call that object a node. Two fields: value, and next.
Student: So the list is a chain?
Dr. Example: Exactly a chain. And the only thing you keep a handle on is the
first link. We call it the head.
Dr. Example: If head is null, the list is empty. That is the whole definition.
Student: How do you get to the last one?
Dr. Example: You walk. Start at head, follow next, follow next, until next is
null. That walk is called traversal and it is the thing you will write fifty
times this semester.
Dr. Example: Which means finding the k-th element costs k steps. Order n in the
worst case. An array does it in one.
Student: Then why would anyone use a linked list?
Dr. Example: Good. Because inserting at the front is free. Make a node, point it
at the old head, call it the new head. Two assignments, done, no matter how long
the list is.
Dr. Example: In an array you would have to shift every element over one slot.
Dr. Example: So the trade is random access for cheap insertion. Neither one wins
everywhere. Picking correctly is most of this course.
Dr. Example: Let me write the insert.
Dr. Example: node = new Node(value). node.next = head. head = node. That is it.
Student: Does the order of those lines matter?
Dr. Example: It matters enormously. Flip the last two and you point the new node
at itself and lose the entire list. Draw the boxes before you type.
Dr. Example: On Wednesday we do deletion, which is where people actually lose
their lists, and then doubly linked lists.
Dr. Example: Homework one goes up tonight. Build the list, insert, delete,
length. See you Wednesday.
