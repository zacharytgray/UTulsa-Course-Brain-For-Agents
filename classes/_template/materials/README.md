# materials

Mostly empty. Course files live in the class's workdir (`workdir:` in class.md), not here:
everything from Blackboard is mirrored into `harvey/`, and anything placed by hand goes in
the workdir's own `materials/`. This folder is only for the rare text-native artifact that
belongs in git — a rubric pasted as markdown, an exam review converted to text.

Name those `YYYY-MM-DD-<slug>.md` when there's a natural date, otherwise a descriptive slug.
