# materials

The rare text-native artifact only: a rubric pasted as markdown, an exam review converted
to text. Binary course files (slide decks, PDFs, handouts) live outside the repo, in the
class's `workdir` under `materials/` — see `workdir:` in class.md.

Name dated things `YYYY-MM-DD-<slug>.md` (a lecture's notes, a handout from a given day).
Otherwise use a descriptive slug, e.g. `grading-rubric.md`.
